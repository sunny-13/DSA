1. How to check if a number is prime : 
-> Check from 2 to sqrt(n) and check if any one divides it. (Because divisors always exist in pairs)
-> Sieve : This algorithm till n marks which is prime and composite. (If n <= 10 million, because of memory which is O(n))
    See make an boolean array isPrime till n (keep size according to readibility : n+1).
    Initialise it will all true.
    Now loop goes something like this : 
    for(int i=2; i*i<n ; i++) {
        if(!isPrime[i]) {
            continue; (Now understand this : if this not prime, that means we have it's prime factor, so that will itself divide the bigger number)
        }
        for(int j=i*i; j<=n; j+=i) {
            isPrime[j] = false;
        }
    }
    Time complexity:
    See each prime marks approx : n/prime times.
    So total becomes : n/2 + n/3 + n/5 + ...
    So on taking n common = n * (1/2 + 1/3 + 1/5 + ...)
    The later part complexity using Harmonic sum of progression for primes is log(log(n))
    Therefor TC = n * log(log(n));
    SC (since make a prime array of n length) = O(n).
